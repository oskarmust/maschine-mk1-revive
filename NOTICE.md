MK1 Revive is based on andy83-projects/maschine-mk1-revive. Original credits
and notices are retained. The upstream repository did not include a root
license file at the fork point; this fork does not assign a new license to
that pre-existing code.

The optional Freedoom engine uses ozkl/doomgeneric at the commit pinned by
the Git submodule, under GNU GPL version 2 or later. See
third_party/doomgeneric/LICENSE. The complete engine source and MK1 backend
are included in the accompanying source archive. The distributed engine
binary is built from those sources with scripts/build-freedoom.py.

Freedoom Phase 1 0.13.0 game data is separately licensed; see the license,
credits and source URL in assets/freedoom/ and the app's Resources/freedoom/.
